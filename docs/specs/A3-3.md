# A3-3 / S3-3 白标：品牌与主题、SEO 与统计

任务：`11` S3-3 的剩余部分（品牌 / 主题 / 布局 / SEO / 统计代码）与 A3-3 的剩余部分（`/brand`、`/seo` 两个后台页面）。功能开关与年龄门已由契约 0.39.0 完成，本 spec 不碰那两段。

目标：运营能在后台改站名、Logo、配色、布局、SEO 模板与统计代码，保存后前台几秒内生效；统计代码只有超管能看能改。

> 进度：四个切片全部完成。后端：切片 1（品牌 / 配色 / 布局，契约 0.51.0）、切片 2（SEO / 统计代码，契约 0.52.0，含 `analytics` 进前台下发），领域层 + HTTP 层测试与 curl 实测 65 + 53 项。
> 页面：切片 3 `/brand`（三段分别保存 + 右侧前台预览 + 配色卡片内的效果示意）、切片 4 `/seo`（模板「点击插入」与示例预览、收录与分享、站长验证、统计代码按权限显示），15 个单测 + 无头 Chrome 50 项。
>
> 实现中补的决定：**页面预览只画示意图**，不嵌真实前台（前台渲染还没做，W3-4 / W0-x）。预览用的预设色板在前端另存一份（`branding-utils.ts`），
> 因为后端只存编码、色板最终由前台 CSS 变量定义；这份副本只影响预览，写明了用途。

## 范围

| 段 | 后台接口 | 页面 |
| --- | --- | --- |
| `site` 品牌 | `GET /api/admin/brand`（一次返回三段）、`PUT /api/admin/brand` | `/brand` 第一张卡 |
| `theme` 配色 | `PUT /api/admin/theme` | `/brand` 第二张卡 |
| `layout` 布局 | `PUT /api/admin/layout` | `/brand` 第三张卡 |
| `seo` SEO | `GET/PUT /api/admin/seo` | `/seo` 上半部分 |
| `analytics` 统计代码 | `GET/PUT /api/admin/analytics-code` 🔐 | `/seo` 最后一张卡（按权限显示） |

不在范围：前台按这些配置渲染（`11` W3-4 SEO、W0-x 主题）、OG 卡片生成（S3-8）、sitemap / robots.txt 的实际输出（W3-4）、年龄门与功能开关（已完成）。

## 决定

1. **GET 合并、PUT 分段**：`/brand` 页面一次 `GET /api/admin/brand` 拿到 `site`/`theme`/`layout` 三段（一个页面三张卡，发三次请求没意义），但保存分成三个 PUT——docs/06 第 16 节要求「各段分别保存」，改配色不该把正在编辑的布局一起写回去。`docs/07` 的三行按此标注。
2. **统计代码独立接口 + 独立权限**：`GET/PUT /api/admin/analytics-code` 都要 `seo.analytics_code`（迁移 00003 已有这个权限点，默认只有超管）。不把它塞进 `GET /api/admin/seo` 的响应里——那样没有权限的运营虽然改不了，却能读到代码内容。
3. **统计代码下发前台**：`GetPublicSiteConfig` 原本把 `analytics` 排除在外，等于这段配置只能写不能用。统计代码最终要原样注入页面 HTML，本身就是公开内容，所以加进 `GET /api/v1/site-config`。
4. **统计代码不做 HTML 清洗**：它就是要原样注入的第三方脚本（清洗掉 `<script>` 就没有意义了），与广告素材、静态页正文那条「白名单清洗」的路线**有意不同**。控制手段是：仅 `seo.analytics_code`（超管）可改、每次改动记审计、长度上限、前台受 CSP 约束（`docs/04` 第 12 节）。保存时只拒绝明显的误填（`</script>` 不闭合之类不做校验，避免假安全感）。
5. **枚举与颜色一律白名单，坏值 400**：皮肤预设、深浅色、页头样式、卡片样式、播放形态、封面比例、字体都是固定枚举；颜色只收 `#rgb` / `#rrggbb`；圆角 0–32px。不做「坏值静默兜底」——配色或布局写错会让全站歪掉，静默兜底会让运营以为自己改成功了。
6. **SEO 模板的页面键与变量都由后端登记**：页面 9 个（`home`/`list`/`play`/`rank`/`drama`/`topic`/`search`/`channel`/`tag`），变量 12 个（docs/06 第 17 节的清单）。`GET /api/admin/seo` 把页面与变量清单一起返回，前端的「点击插入」照着渲染，不在前端抄一份；模板里出现未登记的 `{变量}` 直接 400（写错变量名会在标题里露出 `{xx}` 给用户看）。
7. **Logo 与 favicon 存相对 key**：与剧集封面一致（后台上传产生的 `img/...`），由前台经图片线路拼完整地址；留空表示用站名文字（docs/06）。本次只校验格式与长度，上传入口随 A6-x 图片管线。
