# A1-2 / A1-3 后台内容页面

任务：`11` A1-2（剧集列表、剧集编辑）与 A1-3（标签、维度与取值、专题）。依赖 S1-3（后台内容接口，契约 0.7.0）已完成；分集的视频状态按契约 0.9.0（S1-5）显示。
目标：运营能在后台录入并维护一部剧的资料、标签、维度取值与分集，并管理标签、筛选维度与专题（M1「后台录入一部剧」）。
演员页面与剧集编辑页的演员表分区已删除（`11` A1-3a，契约 0.11.0），下文不含演员。

## 范围

| 页面 | 路由 | 功能（`06` 对应章节） |
| --- | --- | --- |
| 剧集列表 | `/dramas` | 搜剧名 / 别名 / `#ID`，按状态（含定时未到点）、标签、维度取值筛选，排序，页码分页；新建（剧名 + 简介 → 草稿）；批量上架、下架、转草稿、打标签、加入手选专题、设维度取值；放回收站（第 4 节） |
| 剧集编辑 | `/dramas/:id` | 剧资料、标签、维度取值、分集四个分区，各自保存；分集显示视频状态（只读）；放回收站（第 5 节） |
| 标签 | `/tags` | 搜索、状态与是否已合并筛选、新建 / 编辑、并入其他标签（第 7 节） |
| 筛选维度 | `/taxonomies` | 维度与取值的新建 / 编辑 / 删除，拖拽排序（第 11 节） |
| 专题 | `/topics` | 搜索与筛选、新建 / 编辑（含 FAQ、自动规则）、手选剧（按剧名或编号添加、拖拽排序）、删除（第 14 节） |

范围外：试播（第 37 节，依赖 S1-8，按钮禁用并说明）、看数据（A4-1）、分集转封装的提交与重试（A1-5）、图片上传（还没有上传接口）、回收站页面（A4-3）、由 OpenAPI 生成 TS 类型（X0-5，先手写并与契约逐字段对齐）、Playwright 冒烟（A0-5）。

## 规则

- 列表的搜索、筛选、排序与页码写在 URL 查询串里，刷新或分享地址后保持；换筛选条件回到第 1 页。
- 只有「查看」权限时页面只读：不显示新建，表单与操作按钮禁用并说明原因（真正的判断在后端）。
- 关联选择调用其他页面的读接口（搜标签、列出维度与取值、搜专题、搜剧）：当前角色没有该页面的「查看」权限时，对应控件禁用并说明原因，不发出注定 403 的请求（后台任何读请求 403 都会跳到无权限页）；维度取值分区改为只列出本剧已选的取值。
- 剧集编辑页每个分区单独保存；有未保存的修改时离开页面或切换分区前提醒。剧资料是整体保存（契约 0.7.0）。
- 「更新至 N 集」只算可播放（转封装完成）的分集，没有时显示「暂无可播分集」；分集增删改后刷新。
- 拖拽排序：拖动手柄、方向键或上移 / 下移按钮调整顺序，点「保存顺序」后提交（维度、取值）；专题手选剧的顺序随专题的保存一起提交。
- 多选的搜索选择框点选后不关闭，焦点留在搜索框，可以接着输入下一个关键词；换关键词时保留上一次的结果直到新结果返回。
- 写操作成功后提示结果并刷新相关数据；失败显示后端返回的中文提示（含请求编号）。

## 验收

- `typecheck`、`lint`（0 错误）、`test`、`build` 通过；表单转换、排序、编号解析、关联选择的权限判断等纯逻辑有 Vitest 单测。
- 无头 Chrome 对接本地后端，以超级管理员走通全部页面的主要操作（新建维度与取值 → 标签 → 剧集 → 编辑四个分区 → 批量 → 专题手选剧 → 合并标签）；以只有「剧集」查看权限的角色确认页面只读、关联筛选禁用且没有任何 403 请求。

## 假设（需确认）

1. 剧集与分集封面先填写资源路径或地址；上传随存储任务提供。
2. 列表多选只在当前页内，翻页后清空。
3. 剧集编辑页的标签分区按名称搜索，只列出未合并的标签。
4. 不放宽后端权限点：编辑剧集的角色需要同时授予「标签」「筛选维度」（批量加入专题还要「专题」）的查看权限，否则对应的关联选择不可用。
