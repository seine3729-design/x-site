# S4-6 · 授权测试采集器

## 目标

为开发环境提供 `collectortool`：只从人工核验、明确授权的 catalog manifest 获取短剧文案、封面与视频，分别写入后台配置的图片/视频主 `storage_provider`，用于测试媒体管线。

## 范围

- 输入：JSON manifest，包含来源编号、权利基础与引用、精确下载域名及各域名的 `robots_url`、短剧标题/简介、WebP/AVIF 封面和 MP4/MOV/WebM/MKV 视频。
- 合规门禁：必须有 `owned`、`licensed`、`public_domain` 或 `cc_by` 权利声明及引用；`licensed` 必须未到期。robots 允许不等于授权，两者缺一不可。
- 下载：精确域名 allowlist、HTTPS、`netguard` SSRF 防护、禁止重定向、固定 User-Agent、每请求超时、请求间隔、可信 `Content-Length`、图片 15 MiB/视频 4 GiB 限制、MIME 与基础文件头复核。
- 存储：封面写当前图片主存储的 `img/collector/<run_id>/...`；原视频写当前视频主存储的 `video/source/collector/<run_id>/...`。不通过 CDN/`storage_line` 写入，不下发存储凭据。
- 清理：每次 stage 强制生成权限为 `0600` 的本地报告；`collectortool cleanup` 仅可按报告删除同一 `run_id` 的 collector 前缀对象。中途失败立即补偿已写对象，清理失败保留恢复报告。

## 范围外

- 任意网页 HTML 解析、自动发现来源、付费墙/登录墙/验证码绕过、反爬绕过、代理轮换、Cookie/账号抓取。
- 未提供书面授权或明确开放许可的真实联网采集。
- 自动创建剧集/分集、自动上架、自动发布；本切片仅暂存媒体和输出文案结果，人工预览后再接 S4-6 的内容入库与 `media_transcode`。
- 生产环境运行：命令只允许 `APP_ENV=development`。

## 命令

```bash
# 只检查结构与授权声明，不联网
./dev.sh go run ./cmd/collectortool validate \
  -manifest internal/collector/testdata/authorized-manifest.json

# 对已授权的真实 HTTPS 来源暂存素材；报告必须保存，供测试结束后的精确清理
./dev.sh go run ./cmd/collectortool stage \
  -manifest /absolute/path/to/authorized-catalog.json \
  -report /tmp/xsite-collector-report.json

# 测试结束后按报告回收
./dev.sh go run ./cmd/collectortool cleanup \
  -report /tmp/xsite-collector-report.json
```

`testdata/authorized-manifest.json` 仅为离线 `validate` 样例，使用保留域名，不能用于 `stage`。

## 验收

1. 缺少授权引用、许可过期、未登记域名、非 HTTPS、robots 跨域、错误 MIME 或重复编号的 manifest 均拒绝。
2. robots 拒绝、重定向、超大小、Content-Type/魔数不符时不写入或补偿删除已写对象。
3. 合规素材分别写入图片/视频主存储，key 位于 collector 前缀；报告记录物理目标快照，cleanup 不会删除 collector 前缀外的对象。
4. 默认不发布、不创建剧集和分集、不触发 HLS 转码；后续人工确认后再接内容入库与既有转码队列。
