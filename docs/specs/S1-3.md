## 规则

- **列表**：页码分页 `?page=1&page_size=20`（`page_size` ≤ 100），返回 `{ list, total, page, page_size }`。后台表格要显示总页数并跳页，这与前台的游标分页不同。维度（含取值）与一部剧的分集数量少，一次返回全部。
- **保存**：`PATCH` 是整体保存，未传的可选字段按新建时的默认值保存；新建与保存都返回保存后的完整记录。
- **剧集列表**：`q` 匹配剧名或别名（pg_bigm），也可以是 `#ID` / 纯数字编号；筛选 `status=draft|published|scheduled|offline`（`scheduled` = 已上架但定时未到点，`published` 只含已经可见的）、`tag_id`、`term_id`；排序 `sort=latest|updated|hot|recommend`，默认按编号倒序。不含回收站中的剧。
- **剧集状态**：新建为草稿。保存或批量上架时，若为 `published` 且没有 `publish_at`，写入当前时间（作为上架时间，「最新」排序要用）；`publish_at` 在未来即定时上架。`hot_score` 随 `view_base` 修改同步为 `view_base + view_count`。
- **删除剧集**：写 `deleted_at` 进回收站，关联与分集保留以便还原；已删除的剧不能查看或修改（404）。
- **剧集关联**：标签 / 维度取值各自整体替换。单选维度最多一个取值。不存在的 ID 返回 400。
- **批量**（一次 ≤ 200 部）：`publish`、`offline`、`draft`、`add_tags`（追加）、`add_to_topic`（只能加入手选专题，追加在末尾）、`set_terms`（多选维度追加，单选维度替换）。返回受影响的剧数。
- **分集**：集号同一部剧内唯一（重复返回 409）；试看秒数不超过时长（时长为 0 表示未知，不限）。增删改后刷新 `drama.latest_episode` = 最大集号。
- **标签**：不能删除，只能「并入」另一个标签：源标签记 `merged_into_id`，它的剧挂到目标标签，原先并入源标签的也改指目标；不能并入自己（400），源标签或目标标签已被合并时 409。已合并的标签不能再给剧选用（400）。
- **维度 / 取值**：删除维度连同取值；取值 `slug` 在维度内唯一，设为频道的取值 `slug` 全站唯一，`code` 填写时全站唯一；排序接口按传入顺序重排，必须传入全部 ID（与现有不一致时 409，刷新后重试）。已有剧在某维度选了多个取值时，该维度不能从多选改为单选（409）。
- **专题**：手选专题用 `PUT /topics/:id/dramas` 整体替换（数组顺序即展示顺序；回收站中的剧保留在专题里，还原后回到原位置）；自动专题只保存规则，选剧在 S1-4 执行。规则为 `{ term_codes, tag_id, sort, window, limit }`：同时满足全部取值编号与标签，按 `latest|hot|recommend` 排序，上新窗口 `all|7d|14d|30d|90d`，取前 1–60 部（默认最新、不限、24 部）；保存自动专题时校验取值编号与标签存在。删除不进回收站。
- **slug**：小写字母、数字与连字符（`a-z0-9-`，不以连字符开头或结尾），≤ 64，保存前转小写；标签、维度、取值、专题不填时自动生成「前缀-6 位随机」（标签 `t-`、维度 `f-`、取值 `v-`、专题 `s-`，如 `t-k3j9x2`），碰巧冲突时换一个重试；剧集可留空。
- **冲突**：唯一键冲突返回 409 并说明是哪一项（如「slug 已被使用」）。
