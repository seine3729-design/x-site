# S3-4 搜索（前台联想与剧集结果）

任务：`11` S3-4 的剩余部分——前台搜索接口。热搜计数、后台热搜词与热搜榜已随 `docs/specs/A3-4.md` 完成（契约 0.27.0，迁移 00020），本 spec 只做「联想」与「剧集结果」，并把 A3-4 留下的 `HotsearchService.Record` 接上。

目标：用户在前台搜剧名能搜到已上架的剧，输入时能得到联想；每次搜索都计入热搜，供后台选品。

> 进度：两个接口都已完成（契约 0.47.0，迁移 00035）。两个切片的代码共用一个领域服务，所以一起落地、只升了一次契约版本。
>
> 实现中追加的两个决定（原计划里没有）：
> 1. **大小写不敏感要靠小写函数索引**：实测 `ILIKE` 用不上 pg_bigm 的 GIN 索引（`SET enable_seqscan = off` 后仍是顺序扫描），
>    所以迁移 00035 给 `lower(title)` 与 `lower(aliases_text(aliases))` 各建一条 pg_bigm 索引，SQL 按 `lower(…) LIKE` 写，
>    与领域层统一转小写的搜索词对齐。实测新查询走 BitmapOr + 两条新索引。
> 2. **缓存键必须带排序**：`cursorKey` 对第一页只返回「0:条数」，键里不带排序时换 `sort` 会读到上一种排序的缓存
>    （curl 实测踩到，已补 `TestSearchCacheKeyIncludesSort` 守住）。

## 范围

| 接口 | 说明 |
| --- | --- |
| `GET /api/v1/search?q=&sort=&cursor=&limit=` | 搜索结果（只有剧集），游标分页 + `total`，ETag + 共享缓存 60 秒 |
| `GET /api/v1/search/suggest?q=&limit=` | 剧名联想，最多 10 条；`features.search_suggest` 关闭时 404；按设备限流；缓存 5 分钟 |

不在范围：Web 搜索页（`11` W3-1/W3-2）、APP 搜索页（M3-1）、Meilisearch 迁移（`03` 第 3.3 节的后续路线）、搜索历史（存在客户端本机，`04` 第 9 节）。

## 决定

1. **规范化共用一套**：把 `ops.NormalizeSearch` 的实现抽到 `internal/textnorm.Search`，`ops.NormalizeSearch` 保留为包装（调用方与既有测试不变），搜索接口的匹配、缓存键与热搜计数都用它。否则「同一个词」在搜索与热搜两处会不一致（例如全角与大小写）。
2. **MVP 不做相关性排序**：匹配用 `pg_bigm` 的 `LIKE`（剧名或别名，与后台剧集搜索同一套索引），排序沿用前台列表的白名单（最新 / 最热 / 推荐），**默认最热**——热度是搜索场景下合理的相关性代理，而且能复用现成的游标分页与 `(status, 排序列, id)` 复合索引。真正的相关性打分等 Meilisearch（`03` 第 3.3 节已写明路线）。
3. **复用前台剧列表查询**：给 `PublicDramaFilter` 加 `Pattern`，搜索走和探索 / 频道 / 标签同一个 `publicDramaSQL`，只多一个 `(title LIKE $n OR aliases_text(aliases) LIKE $n)` 条件。不新开一套列表 SQL。
4. **热搜计数只在第一页记一次**：翻页不重复计数；缓存命中也要计数（用户确实搜了这一次）。计数失败只记日志，不影响搜索结果。
5. **联想不计热搜**：输入过程中的半截词会污染热搜榜与「片库没有」的选品依据。
6. **联想另算一套限流与开关**：按设备每分钟 60 次（固定窗口，复用 `cache.Counter`），超出 429 + `Retry-After`；`features.search_suggest` 关闭时整个接口 404（与排行榜一致，前台据此隐藏实时联想）。
7. **搜索结果页不做年龄门与敏感标签过滤**：敏感标签影响的是标签页收录（`02` 第 2.4 节），搜索结果页本身输出 `noindex`（`04` 第 9 节），这里不额外过滤。

## 切片

1. **剧集结果**：`textnorm` 抽取 → `PublicDramaFilter.Pattern` → `content.SearchService.Search` → `GET /api/v1/search` → 接上热搜计数 → 契约、文档、测试、curl。
2. **联想**：`SuggestPublicDramas` 查询 → `SearchService.Suggest`（开关 + 缓存）→ `GET /api/v1/search/suggest`（限流）→ 契约、文档、测试、curl。
