# 12 · 对象存储与多线路

本文定义视频切片、封面等媒体资源的**存储源配置**（S3 / Cloudflare R2 / 自定义）、**访问线路**（一个存储源可挂多条线路）、**按客户端 IP 动态返回线路**和**前台/APP 切换线路**的完整方案。它取代 `02` 第 4.1 节、`03` 第 4.1/4.3 节、`06` 第 30 节中旧的单层「线路」设计，其他文档中的「线路」均以本文为准。

## 1. 概念与关系

```
存储源 storage_provider（S3 / R2 / 自定义）           ← 后台「存储源」页配置凭据、桶、用途
   │ 1
   │ n
访问线路 storage_line（CDN 域名 / 直连 / 自定义域名）   ← 后台「线路」页配置域名、签名、地区规则、优先级
   │ 1
   │ n
地区规则 storage_line_rule（国家 / 省份 / 运营商 / ASN） ← 决定这条线路给哪些用户

媒体对象 media_object（逻辑文件：某集的清单、切片目录、封面）
   │ 1
   │ n
副本 media_replica（该对象在哪些存储源上可用）          ← 上传主存储 + 异步复制到镜像存储
```

- **存储源**回答「文件放在哪」：一个桶 + 一组凭据。
- **线路**回答「用户从哪下载」：一个对外访问入口（域名 + 签名方式），指向某个存储源。同一存储源可以挂多条线路，例如「R2 + 自定义域名」「R2 + 国内 CDN 回源」。
- **地区规则**回答「这条线路给谁用」：按客户端 IP 解析出的国家/省份/运营商匹配。
- **副本**回答「这个文件在哪些存储源上有」：只有存在副本的存储源，其线路才会出现在候选列表里。

## 2. 存储源类型

| 类型 | 说明 | 必填配置 | 签名方式 |
| --- | --- | --- | --- |
| `s3` | AWS S3 或任何 S3 兼容服务（阿里云 OSS、腾讯云 COS、华为云 OBS、Wasabi 等） | `region`、`bucket`、`access_key_id`、`secret_access_key`；非 AWS 时填 `endpoint` | S3 预签名（SigV4） |
| `r2` | Cloudflare R2 | `account_id`、`bucket`、`access_key_id`、`secret_access_key`；`endpoint` 自动生成为 `https://<account_id>.r2.cloudflarestorage.com`，`region=auto` | S3 预签名（SigV4）或绑定自定义域名后用 CDN 鉴权 |
| `custom` | 自定义源：自建 S3 兼容（SeaweedFS、Garage、Ceph RGW）或只读 HTTP 源（自建 Nginx、FTP 资源机的 HTTP 出口） | 子类型 `s3_compatible`：`endpoint`、`bucket`、`path_style`、凭据；子类型 `http_origin`：`base_url`、可选回源鉴权头 | S3 预签名 / HMAC 令牌 / 无 |

通用字段：

| 字段 | 说明 |
| --- | --- |
| `name` | 后台显示名，如「R2-主存储」「OSS-华东镜像」 |
| `purpose` | 用途：`video`（切片与清单）/ `image`（封面、头像、广告图）/ `both` |
| `role` | `primary`（新内容写入）/ `mirror`（异步复制）/ `readonly`（只读历史资源） |
| `path_prefix` | 桶内前缀，如 `media/`，便于多环境共用一个桶 |
| `max_presign_ttl` | 预签名最长有效期（秒），默认 600，上限 7 天（S3/R2 协议上限） |
| `status` | `active` / `draining`（不再写入，只读） / `disabled` |
| `credential_enc` | 凭据密文（信封加密，见 `10` 第 3.2 节） |

**R2 注意事项**
- `r2.dev` 公共子域有速率限制，只用于测试；线上用绑定在 Cloudflare 的自定义域名作为线路。
- R2 不收出网流量费，适合作为主存储；国内访问质量取决于网络环境，通常需要搭配国内 CDN 回源或国内镜像存储。
- R2 预签名使用 S3 协议，`region` 固定为 `auto`。

**凭据规则**
- 读写分离：写入凭据（上传、复制、删除）只在受信任服务端进程中使用（API 同源上传代理与 worker）；预签名用只读凭据（只有 `GetObject` 权限）。
- 凭据在后台只能写不能读：保存后显示「已配置（末 4 位 ****abcd）」，修改时需重新输入并通过二次验证。
- 凭据永远不会下发给浏览器、前台或 APP。

## 3. 线路

### 3.1 字段

| 字段 | 说明 |
| --- | --- |
| `provider_id` | 所属存储源 |
| `name` | 用户可见名称，如「线路 1 · 电信优化」；空则显示「线路 N」 |
| `kind` | `video` / `image` |
| `base_url` | 访问入口，如 `https://v1.example.net`；选「直连存储」时由存储源 endpoint + bucket 生成 |
| `access_mode` | `presign`（直接给存储预签名 URL）/ `cdn`（经 CDN 域名访问） / `public`（公开读，仅用于封面等公开资源） |
| `sign_type` | `s3_presign` / `hmac_token`（`?t=<exp>&s=<hmac>`，边缘函数验签）/ `cdn_vendor`（CDN 厂商的 URL 鉴权，见 3.3）/ `none` |
| `sign_key_ref` | 签名密钥引用（密钥本身在密钥管理中，后台只填名字） |
| `token_ttl` | 链接有效期（秒），默认 600 |
| `priority` | 优先级，数字越大越靠前 |
| `weight` | 同优先级内的流量权重（1–100），用于灰度和分流 |
| `region_scope` | `rules`（按地区规则）/ `global`（兜底，所有地区可用） |
| `video_process` | 历史兼容：`standard` / `text_to_image`（旧混淆封装，需客户端还原），新内容一律 `standard` |
| `probe_path` | 健康探测文件路径，默认 `/_probe/256k.bin` |
| `status` | `active` / `watch`（观察中：仍下发但排在后面）/ `disabled` |
| `note` | 备注 |

### 3.2 地区规则 `storage_line_rule`

一条线路可以有多条规则，命中任意一条即视为「本地区线路」。

| 字段 | 示例 | 说明 |
| --- | --- | --- |
| `country` | `CN`、`HK`、`US`、`*` | ISO 3166-1 alpha-2；`*` 表示任意 |
| `province` | `广东`、`*` | 仅中国大陆有意义 |
| `isp` | `电信`、`联通`、`移动`、`*` | 运营商 |
| `asn` | `4134`、空 | 可选，精确到自治系统 |
| `effect` | `include` / `exclude` | `exclude` 用于把某运营商排除出这条线路 |
| `boost` | `0`–`100` | 命中后额外加分，用于「广东电信优先走线路 A」 |

匹配精度（用于排序）：`asn` > `country+province+isp` > `country+isp` > `country+province` > `country` > `global`。

### 3.3 签名方式

| 方式 | 适用 | 生成 | 校验 |
| --- | --- | --- | --- |
| `s3_presign` | 直连 S3/R2/自定义 S3 | 后端用只读凭据对每个对象生成 SigV4 预签名 | 存储服务自身 |
| `hmac_token` | 自有 CDN + 边缘函数（如 Cloudflare Workers 绑定 R2） | `s = base64url(HMAC-SHA256(key, path_prefix + exp))`，对**目录前缀**签名，一个令牌覆盖整集切片 | 边缘函数校验 `exp` 与 `s` |
| `cdn_vendor` | 商用 CDN 的 URL 鉴权（时间戳防盗链） | 按厂商算法生成（适配器模式，每家一个实现） | CDN 边缘 |
| `none` | 公开封面 | 不签名 | — |

HLS 清单里有大量切片地址。为避免逐个预签名带来的 CPU 开销和超长清单，视频线路**优先使用目录前缀签名**（`hmac_token` / `cdn_vendor`）；只有直连存储时才逐个 `s3_presign`，并对签名结果按「对象 + 分钟」缓存。

S1-8 的清单改写一次为一档清单的全部对象签名（`storage.SignService.SignSegments`）：`hmac_token` 对产物的 `s/` 目录签一次，查询串所有切片共用（300 个切片约 0.2ms）；`cdn_vendor` 的密钥与适配器只取一次、地址逐个生成；`s3_presign` 存储源与只读凭据只取一次，`blob.Bucket.PresignGetMany` 只建一次客户端、端点规则只解析一次（AWS SDK 每次解析都会重新编译分区正则），300 个切片约 12ms / 6.7MB，逐个调用约 60ms / 40MB。「对象 + 分钟」缓存尚未实现：直连存储的视频线路访问量大时再加。

## 4. 按 IP 动态返回线路

### 4.1 获取客户端 IP

- 只信任可信代理链：Gin `SetTrustedProxies` 配置 CDN 回源网段与 BFF 网段。
- 取值顺序：CDN 专用头（`CF-Connecting-IP`、厂商的真实 IP 头，且该请求已通过回源鉴权）→ `X-Forwarded-For` 中第一个不可信地址 → 连接地址。
- Web 走 BFF 时，BFF 把浏览器 IP 放在 `X-Forwarded-For`，并带服务令牌，后端只对带有效服务令牌的请求采信该头。
- APP 直接访问 API 域名（经 CDN），按 CDN 头取值。

### 4.2 IP 解析

| 数据 | 选型 | 说明 |
| --- | --- | --- |
| 国家/地区 | MaxMind GeoLite2-Country 或 DB-IP Lite（mmdb 格式） | 全球覆盖 |
| 中国省份 + 运营商 | ip2region（xdb 格式） | 国内省份/运营商粒度更准 |
| ASN | GeoLite2-ASN | 可选 |

- 数据库文件放对象存储，worker 每周下载新版本，校验哈希后发布；API 进程定时检查版本并**原子替换**内存中的读取器（`atomic.Pointer`），不中断服务。
  （S1-6c 当前实现：文件由运维放到 `GEOIP_XDB_PATH`，各进程按 `GEOIP_RELOAD_INTERVAL` 检查 mtime 并原子热替换；从对象存储分发与 `geoip_release` 版本表待做。）
- 查询结果按 IPv4 /24、IPv6 /48 前缀缓存在进程内 LRU（10 万条，TTL 1 小时），单次解析 < 5µs。
  （实测 P50 = 83ns、P99 = 625ns；缓存满时整体清空而非逐条淘汰 —— 解析结果的访问高度集中，省掉 LRU 链表维护更划算。）
- 解析失败或 IP 为内网地址（本地开发）时，地区记为 `XX`，只匹配 `global` 线路；本地开发可用请求头 `X-Debug-Geo: CN/广东/电信` 模拟地区（仅 `APP_ENV=development` 生效）。
- 隐私：IP 只用于本次请求的匹配，不写入数据库；埋点只记录解析后的 `country/province/isp` 和 IP 前缀。

### 4.3 选择算法

```
输入：kind（video/image）、对象所在存储源集合 R、客户端地区 G、客户端偏好线路 P（可选）
1. 候选 = 状态为 active/watch，且 provider ∈ R，且 kind 匹配的线路
2. 过滤：命中 exclude 规则的去掉；健康分 < 30 的去掉（全部被去掉时保留健康分最高的 1 条兜底）
3. 打分：
     score = 匹配精度分(0–60) + boost(0–100) + priority×10 + 健康分×0.3 − (watch ? 50 : 0)
4. 同分按 weight 加权随机打散（同一设备在 10 分钟内结果稳定：随机种子 = 设备ID + 当前10分钟时间片）
5. 取前 N 条（默认 3，后台可配 1–5）
6. 若 P 在候选中且健康，把 P 放到第一位并标记 manual=true
输出：[{ line_id, name, region_tag, recommended, manual, url, expires_at }]
```

- **健康分**（0–100）：由两部分加权得出——服务端探测（每条线路每分钟从 2 个以上探测点拉 `probe_path`，成功率与耗时）占 40%；客户端上报（最近 15 分钟该线路在该地区的首帧耗时、失败率，见第 6 节）占 60%。按「线路 × 国家 × 运营商」分别计算，存 Valkey。
- 结果不可共享缓存（含签名），但「地区 → 已排序线路 ID 列表」可按地区缓存 30 秒，签名在其后逐条生成。

### 4.4 接口

**用户端**

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/v1/lines?kind=video\|image` | 当前地区的线路列表（不含对象地址），用于线路菜单与测速。返回 `region`（如 `CN-广东-电信`）、`lines[{id,name,region_tag,recommended,probe_url}]`、`ttl` |
| GET | `/api/v1/episodes/:id/sources?line_id=` | 选源：在鉴权通过后，按第 4.3 节返回候选线路及**清单地址**（同源加密接口 `/api/v1/hls/...`）；`line_id` 为用户手选线路 |
| POST | `/api/v1/lines/report` | 客户端上报线路质量（批量） |

```json
{
  "code": "OK",
  "data": {
    "episode_id": 42,
    "region": "CN-广东-电信",
    "access": "free",
    "trial_sec": 0,

```

- 清单地址是同源的加密接口（令牌 `kid.载荷.签名` 内含分集、线路、设备哈希、试看秒数与过期时间，`10` 第 4 节），播放器经加密接口取清单（`10` 第 5.3 节）；清单里的切片地址才指向该线路的 CDN 域名（按第 3.3 节签名），`#EXT-X-KEY` 指向 `/api/v1/hls/key/...`。这样页面与网络上都看不到可直接播放的明文清单。

封面等图片资源：列表与详情接口返回图片的**相对 key**，客户端用 `GET /api/v1/site-config` 的 `media.image_bases` 拼接（契约 0.77.0；图片线路一般为 `public` 或长有效期签名）；首选加载失败时自动换下一条。`/api/v1/lines` **不给** `base_url`（它按地区裁剪、也不含对象地址，见上表），所以域名不从那里取 —— 域名池是「全站可能访问哪些域名」的全集，Web 还要用它生成 CSP 的 `connect-src`，按地区裁剪过的列表会漏掉别的地区用户的域名（`04` F）。`media` 段的口径：`status != disabled` 且有 `base_url` 的线路，图片按 `priority` 倒序给完整前缀（含路径前缀）、视频只给 `scheme://host[:port]`；线路与地区规则变更即令 `site.version` +1 并广播失效。图片**不加密**；Web 端用 `fetch` 取回后转临时 `blob:` 地址显示（`04` C.8），因此图片线路必须对站点全部入口域名返回 CORS 头（`Access-Control-Allow-Origin`），线路测试（`/api/admin/storage/lines/:id/test`）检查这一项。

**运营后台**（均需后台会话 + 角色鉴权 + 审计，凭据相关操作 🔐 需重新验证二次因子）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET/POST | `/api/admin/storage/providers` | 存储源列表 / 新建 🔐 |
| PATCH/DELETE | `/api/admin/storage/providers/:id` | 修改（含凭据）🔐 / 删除（有副本引用时禁止，返回 400 并提示先设为 draining 并迁移；S1-6f 已实现） |
| POST | `/api/admin/storage/providers/:id/test` | 连通性测试：写入探测文件 → 读取 → 生成预签名并访问 → 删除；返回每步耗时与错误 |
| GET/POST | `/api/admin/storage/lines` | 线路列表 / 新建 |
| PATCH/DELETE | `/api/admin/storage/lines/:id` | 修改 / 删除 |
| PUT | `/api/admin/storage/lines/:id/rules` | 整体替换地区规则 |
| POST | `/api/admin/storage/lines/:id/test` | 探测：HTTP 状态、耗时、`content-type`、CORS、签名是否生效、能否还原 |
| GET | `/api/admin/storage/preview?ip=&kind=&episode_id=` | **模拟预览**：输入任意 IP，查看解析出的地区和会返回的线路顺序与得分明细 |
| GET | `/api/admin/storage/health?line_id=&range=` | 线路健康看板（按地区、运营商） |
| GET/PUT | `/api/admin/storage/settings` | 全局设置：候选数量 N、默认有效期、智能选线开关、上传主存储、复制策略 |
| POST | `/api/admin/storage/replicate` | 手动触发复制（按剧 / 全部 / 指定存储源）|
| GET | `/api/admin/storage/geoip` | GeoIP 数据库版本与更新时间；`POST` 立即更新 |

**线路与地区规则**的增删改会令 `site.version` +1 并通过 Pub/Sub 广播失效（`domain/storage.LineService` 调 `platform.SiteConfigService.BumpVersion`），各实例秒级拿到新的域名池。存储源与存储设置的变更**暂未接**版本 +1：它们不改 `media` 域名池，靠站点配置缓存的 TTL（进程内 3 秒 / Valkey 30 秒）兜底。线路表本身没有「内存中的线路表」—— 选线每次查库（`atomic.Pointer` 整体替换只用在 GeoIP、站点配置与屏蔽词上）。

## 5. 上传与复制

1. 分集转封装产物统一写入 `role=primary` 的存储源（按 `purpose` 区分视频与图片）。
2. 后台媒体上传会话不向浏览器下发写凭据：创建时按用途解析后台「存储设置」里的图片/视频主存储，并快照该 `storage_provider` 的 endpoint、region、bucket、path style 与 `path_prefix`；流式写入该固定目标，后续修改同一 provider 的物理连接配置只影响新会话。图片最终 key 为 `img/`，视频源为 `video/source/`；完成阶段仅由服务端复制到私有 `ingest/` 暂存桶转码。CDN / `storage_line` 只负责后续读取分发，不作为写入端点。
3. 分集产物写入成功后在同一事务中记录 `media_object` 与主副本 `media_replica`，并通过 River 入队复制任务。
4. 复制任务把 `media_object` 复制到所有 `role=mirror` 的存储源（服务端拉取 → 写入，分片并发；同云厂商内优先用服务端复制 API），成功后写副本记录。
5. 选源时只考虑已有副本的存储源，因此镜像尚未复制完成时不会返回 404 线路。
6. 存储源设为 `draining` 后不再写入；后台提供「迁移到其他存储源」任务，迁移完成后才能删除。
7. 删除内容时异步删除所有副本（进回收站的内容保留 30 天后删除）。

**媒体对象布局**：新分集一次转封装是一个 `hls_dir` 对象 `video/episodes/{episode_id}/{job_id}/`，其中 `master.m3u8` 与各档清单 `v{短边}.m3u8` 在目录顶层，`s/` 下是按内容哈希命名的 AES-128-CBC 密文 `.ts` 切片（`video/mp2t`，`immutable`）。新 profile 固定 4 秒、H.264 + AAC、360p/480p/720p；主清单提供 ABR，播放器从 360p 起播后自动切档。视频线路的目录前缀签名只签 `s/`：拿到切片签名也读不到原始清单，试看裁剪只能经 S1-8 的清单接口。首帧图写图片存储 `img/posters/<hash>.webp`。广告视频由后台上传 worker 写公开 `video/assets/{upload_id}/master.m3u8`；它不绑定分集内容密钥。历史 `hls/` 与 `posters/` key、以及既有 fMP4 的 init/`.m4s` 仍按数据库记录可读，不做批量字符串迁移。

## 6. 前台与 APP 的线路切换

### 6.1 交互
- 播放设置面板「线路」列表：显示线路名、标签（推荐 / 本地区 / 通用 / 手选）、实测延迟、状态（播放中 / 实测最快 / 较慢 / 不可用）。
- 自动模式（默认）：使用接口返回的第一条；起播失败或连续卡顿（10 秒内卡顿 ≥ 2 次）时自动切到下一条，并提示「原线路变慢，已切换到 X」，从原位置续播。
- 手动模式：用户点选线路后记在本机（Web `localStorage` 的 `line_pref`，APP 本地设置），有效期 7 天；之后请求选源时带 `line_id`。手选线路变慢时只提示，不自动换；连续失败 3 次后提示「手选线路暂不可用，已切回自动」。
- 「刷新当前线路」：重新请求选源拿新签名地址，从原位置续播。
- 测速：对 `/api/v1/lines` 返回的 `probe_url` 并发发起 `Range: bytes=0-262143` 请求（最多 3 条并行，单条超时 4 秒），按耗时排序；测速结果缓存 10 分钟。

### 6.2 质量上报 `POST /api/v1/lines/report`

```json
{ "items": [
  { "line_id": 12, "kind": "video", "event": "first_frame", "ms": 820 },
  { "line_id": 7,  "kind": "video", "event": "error", "reason": "timeout" },
  { "line_id": 12, "kind": "video", "event": "switch", "to_line_id": 7, "trigger": "auto_stall" }
] }
```

- 事件：`probe`（测速）、`first_frame`、`stall`、`error`（`timeout`/`http_4xx`/`http_5xx`/`cors`/`decode`）、`switch`。
- 服务端按「线路 × 地区 × 运营商」聚合到 Valkey（15 分钟滑动窗口），参与健康分计算；同时写入埋点用于看板。
- 每设备每分钟最多 30 条，超出丢弃。

### 8.1 存储源（`/admin/storage/providers`，仅超管可改）
- 列表：名称、类型（S3/R2/自定义）、用途、角色、桶、状态、已用容量（定时统计）、对象数、最近测试结果。
- 新建/编辑表单按类型切换字段：
  - S3：Region、Bucket、Endpoint（可选，S3 兼容服务填写）、Path-style 开关、Access Key、Secret Key、只读 Key（可选）。
  - R2：Account ID、Bucket、Access Key、Secret Key、只读 Key；自动显示生成的 Endpoint。
  - 自定义：子类型（S3 兼容 / HTTP 源）；S3 兼容同 S3 字段；HTTP 源填 Base URL 与回源鉴权头。
- 操作：测试连通性（逐步显示写入/读取/预签名/删除结果）、设为主存储、设为镜像、停止写入（draining）、迁移数据、删除。

### 8.2 线路（`/admin/storage/lines`）
- 列表：名称、类型（视频/图片）、所属存储源、访问方式、签名方式、优先级、权重、地区规则摘要、健康分（按主要地区）、状态。
- 编辑：基础字段 + 地区规则编辑器（国家/省份/运营商下拉 + 包含/排除 + 加分），支持拖拽调整优先级。
- 操作：测试线路、设为观察、停用、复制线路。

### 8.3 选线预览与健康（`/admin/storage/preview`）
- 输入 IP（或选择「国家 + 省份 + 运营商」），可选选择某一集，展示：解析结果、命中的规则、每条线路的得分明细、最终返回顺序和示例签名地址（脱敏）。
- 健康看板：线路 × 地区热力图（首帧 P50、失败率、切换次数），可下钻到 15 分钟粒度。

### 8.4 存储设置（`/admin/storage/settings`）
- 候选线路数量、默认链接有效期、智能选线开关、视频/图片主存储、上传后自动复制、GeoIP 数据库版本与手动更新。
- **交付自检**：页面顶部显示 `GET /api/admin/storage/settings` 返回的 `delivery`。选源只从「产物副本已就绪的存储源」上挑线路（第 4.3 节），所以主存储上没有可用线路时，上传、转码与副本复制全部显示成功，前台却拿不到线路、播放返回 503「暂无可用线路」。自检对视频与图片分别检查主存储（设置里指定的，或按第 5 节回退规则解析出的）上有没有 `status != disabled` 的线路，报出三类问题并给出「去配置存储线路」入口：
  - `no_primary`：没有可写入的主存储，上传本身就会失败；
  - `no_line_on_primary`：主存储上没有可用线路，但别的存储源上有（线路挂错了存储源）；
  - `no_line_at_all`：全站都没有该类型的可用线路。

## 9. 安全要求

- **凭据**：信封加密存储；写入与只读凭据分开；后台不回显；修改需二次验证并记审计（不记凭据内容）。
- **SSRF 防护**：自定义 Endpoint/Base URL 的测试与回源请求，在生产环境禁止解析到内网与保留地址段（`10/8`、`172.16/12`、`192.168/16`、`127/8`、`169.254/16`、`::1`、`fc00::/7` 等），只允许 `https`；开发环境可通过配置放开（`EGRESS_ALLOW_PRIVATE`：未设置时 development 放开、其他环境禁止，production 不允许开启）。校验在 `internal/netguard`（S1-6 资源机已使用）：域名的任一解析结果被禁止即拒绝，之后只按校验过的 IP 直连、不再重新解析（防 DNS 重绑定）；未指定地址与组播地址始终禁止。
- **签名**：链接有效期默认 10 分钟；签名绑定路径前缀，不能复用到其他剧集；密钥轮换支持双密钥并行（`10` 第 8 节）。
- **CORS**：视频与图片线路都要允许站点全部入口域名（hls.js 与 `BlobImage` 都用 `fetch` 读取响应体），只允许 `GET`/`HEAD`，暴露 `Content-Length`、`Content-Range`。
- **限流**：`/api/v1/lines`、`/sources` 按设备限流（`03` 第 1.1 节选源桶）；`/api/v1/lines/report` 每设备每分钟 30 条。
- **审计**：存储源、线路、规则、设置的每次变更记录前后差异。

## 10. 本地开发

- `./dev.sh up` 启动的 SeaweedFS 作为一个 `custom/s3_compatible` 存储源（`http://seaweedfs:8333`，桶 `xsite-media`、`xsite-assets`），开发环境默认放开 SSRF 限制中的内网地址。
- 本地没有 CDN，线路使用 `presign` 直连；`S3_PUBLIC_ENDPOINT=http://localhost:8333` 用于生成浏览器可访问的预签名地址。
- 地区模拟：请求头 `X-Debug-Geo: CN/广东/电信`，或在后台「选线预览」中输入 IP。
