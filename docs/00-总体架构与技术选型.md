## 2. 四端职责边界

| 端 | 目录 | 语言/框架 | 运行形态 | 主要职责 | 不负责 |
| --- | --- | --- | --- | --- | --- |
| 后端 | `service/` | Go 1.27.3 + Gin 1.12 | 常驻多实例（API + Worker） | 数据权威源、业务规则、鉴权、选源与播放令牌、会员与支付、埋点汇总、任务调度、采集入库、加密与密钥使用 | 页面渲染 |
| 前端 Web | `apps/` | SvelteKit 3 + Svelte 5 + Bun 1.4 | SSR 服务（adapter-bun） | SEO、首屏 SSR、播放器、BFF 聚合、边缘缓存头、PWA | 业务落库（透传后端） |
| APP | `mobile/` | Flutter 3.47 + Dart 3.13 | iOS / Android 原生包 | 沉浸式刷剧、本地续播、推送、域名容灾、端侧安全加固 | 业务落库（调后端） |
| 运营后台 | `admin/` | React 19.3 + Vite 8 | 纯静态 SPA（独立私有域名） | 内容生产、编排、运营、审核、配置、看板 | 直接读写库（走后台 API） |

**关键原则**
- 所有写操作最终落到 `service/`，其余三端都是消费方；参考站是 SvelteKit 单体，本项目把其中的 `/api/*` 与 `/admin` 逻辑全部下沉到 Go 后端。
- `apps/` 的 BFF 只做聚合、裁剪、缓存头和安全头，不持有数据库连接，不保存业务密钥（防盗链密钥、KMS 凭证都只在 `service/`）。
- 运营后台与用户端**域名、证书、网络入口完全分离**；后台 API 只对后台域名开放，可叠加 IP 白名单/零信任网关。
- **用户端接口全部报文加密**（HPKE，`10` 第 5.3 节）：浏览器与 APP ↔ Go 端到端加密，BFF 只透传密文；后台与开放平台接口不加密。视频清单与密钥只经加密接口下发，网页以 `blob:` 地址播放；图片不加密，网页以 `blob:` 地址显示（`adr/0002`）。
- **多语言**：用户端（Web、APP）9 种语言——简体中文、英语、西班牙语、越南语、日语、韩语、泰语、印地语、阿拉伯语（RTL）；文案为 JSON，可经 CDN 更新（`adr/0003`）。运营后台只用中文。
- **账号**：用户名 + 密码，不提供找回密码，忘记只能重新注册（`adr/0001`）。
- **变现**：广告 + VIP 会员（天/周/月/季/年卡），支付宝、微信支付、USDT（`adr/0004`、`03` 第 12 节）。
- **个人中心与福利**：收藏、观看历史（游客存本机，登录并入）、点赞、账号设置、会员等级、金币钱包；福利中心含签到、每日 / 幸运转盘、天天奖券、任务、评论晒图、推广返利、金币商城。金币只能赚不能提现，奖励统一由服务端判定与发放（`13`、`adr/0005`）。

## 3. 技术选型（2026-10 基线）

## 4. 环境与配置

四端统一 `development` / `test` / `production` 三套环境，密钥一律不入库（本地 `.env.local`，线上走 KMS/Vault 注入）。

| 变量 | 作用域 | 说明 |
| --- | --- | --- |
| `APP_ENV` / `PUBLIC_APP_ENV` | apps | 环境标识，由 `scripts/with-env.ts` 写入 |
| `PUBLIC_SITE_URL` | apps | 站点地址；线上留空用请求 Host |
| `CDN_ASSET_PREFIX` | apps | 静态资源 CDN 域名（构建期 + 运行期，两边必须一致）。**留空**：SvelteKit 不允许 Service Worker 与 `paths.assets` 共存，填了构建直接失败（`service_worker_assets`），而 Service Worker 是产品功能（本文第 2 节、`04` D 节）。apps 的边缘加速改用反向代理型 CDN：站点域名整体挂在 Cloudflare 代理后面，`/_app/immutable/*` 在同源地址上被边缘缓存。见 `deploy/prod/README.md` 第 4 节 |
| `EDGE_SHARED_SECRET` | apps / service | 校验 CDN 回源头 `x-edge-secret` |
| `SERVICE_INTERNAL_URL` | apps | BFF 访问后端的内网地址 |
| `BFF_SERVICE_TOKEN` | apps / service | BFF→后端的服务身份（另配 mTLS） |
| `RATE_LIMIT_*_PER_MIN` | apps / service | 分桶限流配额 |
| `VALKEY_URL` | apps / service | 分布式限流与缓存 |
| `DATABASE_URL` | service | PostgreSQL（经 PgBouncer） |
| `KMS_KEY_URI` | service | 字段加密 KEK 地址（Tink KMS URI） |
| `JWT_SIGNING_KEYS` | service | Ed25519 私钥集合（带 `kid`），由密钥管理下发 |
| `API_ENC_KEYS` | service | 用户端接口报文加密密钥 `kid:secret[,kid2:secret2]`，第一把为当前密钥；本地由 compose 用 `API_ENC_SECRET` 组装 |
| `API_ENCRYPTION_REQUIRED` | service | 是否强制加密；未设置时 development 允许明文，其他环境强制，production 不允许关闭 |

| `PLAY_TOKEN_KEYS` | service（API） | 播放令牌签名密钥 `kid:secret[,kid2:secret2]`，第一把签发、全部用于校验；只有 API 进程使用（选源 S1-7、清单与密钥 S1-8），不下发给 CDN；缺失或格式错误时 API 启动失败；本地由 compose 用 `PLAY_TOKEN_SECRET` 组装（`10` 第 4、8 节） |
| `MEDIA_KEKS` | service（worker、S1-8 起 API） | HLS 内容密钥的包装密钥 `kid:secret[,…]`，S2-8 接入 KMS 前使用（`10` 第 7 节）；worker 用它包装新密钥，API 的密钥接口用它解开（API 缺失或格式错误时启动失败）；本地由 compose 用 `MEDIA_KEK_SECRET` 组装 |
| `MEDIA_TRANSCODE_CONCURRENCY` 等 `MEDIA_*` | service（worker） | 转封装开关与参数，见 `11` 第 9.4 节 |
| `GEOIP_DIR` | service | GeoIP 数据库目录（mmdb / ip2region xdb），用于按 IP 匹配线路 |
| `DOMAIN_LIST_SIGN_KEY` | service（离线） | 域名清单签名私钥，只在签发机使用 |
| `FTP_<凭据标识>_USER` / `FTP_<凭据标识>_PASSWORD` | service（只注入 worker） | 资源机账号密码，按后台登记的凭据标识 `cred_ref` 取用；不入库、不进代码与日志，线上由密钥管理注入；账号与密码要成对配置，否则启动失败（`specs/S1-6.md`） |
| `EGRESS_ALLOW_PRIVATE` | service | 连接后台可配置的地址（资源机等）时是否允许内网与保留地址段；未设置时 development 允许、其他环境禁止，production 不允许开启（`12` 第 9 节） |
| `ADMIN_ORIGINS` | service | 运营后台页面的来源（逗号分隔，如 `https://admin.example.com`）；`/api/admin` 写请求的 `Origin` 必须在其中，必填，production 只允许 https |
| `ADMIN_ASSET_BASE` | admin | 带内容哈希的产物的 CDN 前缀（构建期，Vite `base`，要带末尾斜杠）。留空则同源。`index.html` 始终由后台域名发出 —— 会话是 HttpOnly Cookie + Origin 白名单 + CSRF，必须和 `/api/admin` 同源 |
| `NEXT_ASSET_PREFIX` | feedback | `.next/static` 的 CDN 前缀（构建期，Next.js `assetPrefix`）。留空则同源；页面 HTML、RSC 流与 `public/` 始终同源 |

| `EDGE_TRUST_CLOUDFLARE` | 边缘层 | 站点域名挂在 Cloudflare 代理后面时设 `1`：只信任 Cloudflare 回源网段并取 `CF-Connecting-IP` 作为客户端 IP。没有来源白名单就信任这个头等于让任何人伪造 IP |
| `CERTBOT_EMAIL` / `CERTBOT_STAGING` | 边缘层 | 证书到期提醒邮箱；`CERTBOT_STAGING=1` 用 Let's Encrypt staging 演练，不占正式额度 |
| `VITE_ADMIN_API_BASE` | admin | 后台 API 地址（构建期） |
| `--dart-define=ENV/API_SEED_HOSTS/PIN_SET` | mobile | 构建期注入环境、种子域名、证书公钥锁定集 |

## 5. 资源与播放链路（核心）

1. **入库**：采集程序经开放平台（API Key + HMAC 签名）推送，或后台扫描 FTP 资源机入库；命中屏蔽词拒收；新剧为「草稿」。
2. **转封装**：新上传由 Worker 统一转为 MPEG-TS HLS（H.264 + AAC、固定 4 秒 `.ts` 切片、关键帧对齐、360/480/720 多码率阶梯）；按集生成 AES-128 内容密钥。历史 CMAF/fMP4 产物继续兼容播放（详见 `08`、`10`）。
3. **编排**：运营补全资料、分集、标签与上下架；区块编排决定前台呈现。
4. **选源**：`GET /api/v1/episodes/:id/sources`，后端按访问权限、**客户端 IP 解析出的国家/省份/运营商**、线路地区规则、健康分与优先级返回候选线路，每条带**短期签名 URL**（默认 10 分钟）。存储源（S3 / R2 / 自定义）与线路都在运营后台配置，详见 `12`。
5. **测速选线**：客户端对候选线路发 `Range` 请求测速，切到最快线路；手选记本机；遇 429 按 `Retry-After` 退避。
6. **播放**：播放器经加密接口取清单 → 经加密接口取 AES-128 密钥 → 从 CDN 拉切片。清单与 Key 由后端签发且只走报文加密的 `/api/v1/hls/*`，切片直接走 CDN，不经业务进程；Web 以 MSE 播放（`<video>` 为 `blob:`），APP 经本机回环代理。VIP 集非会员只拿到试看清单或 VIP 墙。
7. **容灾**：多线路 + 多 CDN + 多资源机 + 多域名入口；客户端按签名域名清单自动切换（详见 `09`）。

## 6. 版本治理与供应链

- **锁定**：所有依赖精确锁定在锁文件中；CI 只用 `--frozen-lockfile` / `go mod download` + `go mod verify` / `flutter pub get --enforce-lockfile`。
- **冷却期**：新发布版本至少等待 3 天才允许进入锁文件（Bun `[install] minimumReleaseAge = 259200`，单位秒；pnpm 11 `minimumReleaseAge` 单位分钟，默认 1440）。2026 年 axios、TanStack Router 都出现过被投毒版本，暴露窗口均在数小时内。
- **漏洞扫描**：Go `govulncheck`；JS `bun audit` / `pnpm audit`；Dart `osv-scanner`；容器镜像扫描；每周汇总。
- **构建可信**：CI 不在 PR 来自 fork 的任务中写共享缓存；发布用 OIDC 短期凭证；产物签名（cosign）并生成 SBOM。
- **升级节奏**：Go 跟进最新补丁版本（当前 1.27.3，`go.mod` 写 `go 1.27.3`，开发与生产镜像同步）；Flutter 跟季度稳定版滞后一个补丁；SvelteKit/React/Vite 跟小版本；数据库大版本等 `.1` 再升。
