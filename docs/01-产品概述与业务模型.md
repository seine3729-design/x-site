# 01 · 产品概述与业务模型

## 1. 产品定位

面向 C 端的**短剧在线点播平台**，核心体验是「随时随地，追你想看的」。移动优先、沉浸式竖屏连播，广告 + VIP 会员变现，SEO + 多域名回流获客。内容以多集短剧为主，按标签 / 频道 / 专题 / 榜单组织。用户端（Web、APP）支持 9 种语言：简体中文、英语、西班牙语、越南语、日语、韩语、泰语、印地语、阿拉伯语；运营后台只用中文。

## 2. 核心价值主张

- **即点即看**：免注册即可观看（游客身份），进度/追剧/点赞本地记录，注册后无缝并入。
- **沉浸连播**：竖屏刷剧流（`/shua`），滑动换剧、连播下一集，接近短视频体验。
- **强可用**：多线路自动选线测速、多资源机、多域名入口 + 回流页，抗单点故障与域名失效。
- **轻运营**：后台可视化编排首页、白标换肤、批量采集入库、数据看板指导选品。
- **福利留存**：签到、任务、转盘、奖券、邀请返利、金币商城，用金币与会员天数激励日活和拉新（`13`）。

## 3. 用户角色

| 角色 | 身份来源 | 能力 | 数据归属 |
| --- | --- | --- | --- |
| 游客 | 设备级身份（`/api/v1/auth/guest`） | 浏览、观看（免费/非登录墙集）、本机历史/收藏/点赞（登录后并入账号）、评论弹幕（可配）、浏览福利活动（领取需注册） | 仅本设备 |
| 注册用户 | 用户名+密码（不收集邮箱/手机号；**忘记密码无法找回，只能重新注册**） | 游客全部能力 + 跨设备同步、追更提醒、公开计数、看「需登录」集、购买 VIP、会员等级（V0–V7）、金币钱包与福利活动 | 账号 |
| VIP 会员 | 注册用户购买会员卡（天/周/月/季/年） | 注册用户全部能力 + 看「VIP」集；可配免广告 [推断] | 账号 |
| 管理员 | 后台账号 | 按角色管理内容与配置（见下） | 内部 |

> 账号规则：平台不提供任何找回密码的途径（没有恢复码、邮件、短信，后台也不能重设用户密码），忘记密码只能重新注册，原账号数据不迁移。唯一例外是 VIP：用户凭支付凭证联系客服，核验后把剩余会员天数迁到新账号（见第 5 节、`adr/0001`）。

### 3.1 后台管理员角色（可配置，`adr/0006`）

角色在运营后台「权限」目录中配置。系统只内置**超级管理员**：拥有全部权限点（含以后新增的），不能修改权限、停用或删除，适合站点所有者 / 技术负责人。其余角色（如运营、审核员、只读）由超级管理员按团队分工新建，在「角色权限」中按菜单结构授予各页面的「查看」「修改」及单独授权的操作（统计代码、自定义 HTML）。新角色没有任何权限，只能看到被授予「查看」的页面。

## 4. 核心业务流程

### 4.1 内容生产流程
```
采集/FTP扫描 ──► 入库(草稿) ──► 屏蔽词过滤 ──► 补全资料/分集/标签
     ▲                                              │
     │ API Key 推送                                  ▼
  外部采集程序                              资源体检 ─► 资源预热 ─► 上架(可定时)
                                                     │
                                                     ▼
                                   区块编排(首页/频道) + 专题/榜单 ─► 前台呈现
```

### 4.2 用户观看流程
```
进站 ─► 年龄确认门 ─► 建立游客身份 ─► 浏览(首页/探索/搜索/榜单)
                                          │
                                          ▼
                              详情页/沉浸式 ─► 请求选源 ─► 测速选线 ─► HLS播放
                                          │                              │
                              追剧/点赞/评论/弹幕                  续播/连播/试看墙
                                          │                              │
                                          ▼                              ▼
                              触达登录墙/试看结束 ─────────────► 注册/登录 ─► 数据并入账号
                                                                         │
                              触达 VIP 墙（VIP 集试看结束）──────────────► 选会员卡 ─► 支付 ─► 到账开通 ─► 继续播放
```

### 4.3 社区审核流程
```
用户发评论/弹幕 ─► 屏蔽词引擎
   ├─ 直接拦下 ─────────► 拒绝（发不出/不收录）
   ├─ 变成 *** ────────► 照常显示（词替换）
   ├─ 先送审核 ────────► 待审队列 ─► 审核员通过/隐藏/删除 ─► 显示
   └─ 命中无 ──────────► 直接显示（或全局「先审后显」时入队）
用户举报 ─► 举报队列 ─► 处理/驳回（可处罚举报人或被举报人）
```

### 4.4 VIP 购买流程
```
选套餐（天/周/月/季/年）─► 选支付渠道（按客户端与地区过滤：支付宝 / 微信 / USDT）─► 下单（30 分钟有效）
   │
   ├─ 支付宝 / 微信：跳转或扫码支付 ─► 渠道异步通知（验签、核对金额）─► 订单已支付
   └─ USDT：展示本单收款地址与金额 ─► 链上确认（默认 TRC-20）──────► 订单已支付
                                                                         │
                                         会员到期时间 = max(当前到期, 现在) + 套餐天数，写会员流水
                                                                         │
                                        前台轮询订单状态 ─► 提示开通成功 ─► 回到原播放位置
```

### 4.5 福利流程（`13`）
```
注册/登录（游客本机数据并入）─► 福利中心
   ├─ 签到 / 任务（观看、互动、邀请）──► 赠送金币 + 成长值 ─► 升级（权益：倍率、额外次数、折扣）
   ├─ 每日转盘 / 幸运转盘 / 天天奖券（免费次数，服务端定结果，概率公示）──► 金币、会员天数、优惠券、装扮
   ├─ 评论晒图（审核通过 / 精选）──► 金币
   ├─ 推广返利（一级：有效邀请 + 被邀请人付费 10% 折金币，冻结 7 天）
   └─ 金币商城 ──► 会员天卡/周卡、优惠券（开通会员抵扣）、转盘次数、补签卡、装扮
```

## 5. 变现模式

- **广告**：12 类广告位（弹窗、横幅、信息流、贴片、暂停贴片、沉浸流插入、文字链、App 下载浮窗、页脚），支持端定向、权重、频控、排期，统计曝光/点击/CTR。
- **VIP 会员**：注册用户购买会员卡后可看 `access=vip` 的分集；可配置会员免广告 [推断]。
  | 会员卡 | 默认时长 | 说明 |
  | --- | --- | --- |
  | 天卡 | 1 天 | 尝鲜 |
  | 周卡 | 7 天 | — |
  | 月卡 | 30 天 | 默认推荐 |
  | 季卡 | 90 天 | — |
  | 年卡 | 365 天 | — |
  - 时长、人民币价、USDT 价、划线价、角标、上下架、排序都在后台配置；USDT 价单独设置，不按实时汇率换算。
  - 购买叠加顺延（到期时间 = max(当前到期, 现在) + 套餐天数）；MVP 不做自动续费，到期前 3 天站内信 / 推送提醒。
  - 支付渠道：**支付宝**、**微信支付**、**USDT**（默认 TRC-20，可另开 ERC-20）。渠道可按客户端（Web 电脑 / Web 手机 / APP 官网包 / APP 商店包）与地区开关。
  - 应用商店包（App Store、Google Play）销售数字内容须走商店内购，不能直接调起上述三种渠道，见 `05` C.9。
  - 忘记密码时会员随账号丢失；可凭订单号 / 交易哈希联系客服，核验后迁移剩余天数到新账号 [推断]。
- **福利体系（成本项，不直接创收）**：金币只能赚、不能提现；用于留存与拉新，金币可在商城兑换会员天数等，发放预算按广告收入比例控制（`13` 第 7 节）。充值金币预留开关，默认关闭（`adr/0005`）。
- **站群导流 / 互推**：家族站互相导流换量，后台「收入与成本」按月手工登记导流收入。
- **成本登记**：流量费、服务器/数据库费按月手填，看板核算毛利。
- **增长杠杆**：试看 + 登录墙拉注册；推荐权重、初始播放量、榜单置顶可用于推广位售卖 [推断]。

## 6. 合规与容灾设计（功能层面）

这些是系统的**可用性 / 内容合规**能力，文档只描述其软件功能：

| 能力 | 功能说明 |
| --- | --- |
| 年龄确认门 | 进站确认满 18 岁，可配说明文案、拒绝跳转地址、重复询问间隔 |
| 敏感标签隐藏 | 标签可设「确认年龄后才显示、搜索引擎不可见」 |
| 回家的路 | 发布最新/永久/备用域名并实时探活，域名失效时供用户回流 |
| 多线路选线 | 国内/海外分区 + 优先级 + 测速自动切换，单线路故障不影响播放 |
| 多资源机 | 内容分散多台 FTP + 对象存储，降低单点影响 |
| 白标换肤 | 站名/Logo/配色/favicon 一键切换，支持多品牌运营 |
| 配置导出导入 | 整站设置一键备份与迁移（签名校验），用于灾备恢复与换环境 |
| 数据上报暂停 | 可一键暂停前台上报以「止血」，前台照常运行 [推断] |
| PWA | 添加到主屏幕，提供免商店的类 App 入口 |
| 账号身份 | 默认用户名 + 密码，不采集手机号与硬件标识；提供「发布前需验证身份」开关（`features.require_verified_to_post`），按运营地法规启用（如中国大陆要求发布信息前完成真实身份认证） |
| 运营资质 | 按运营地完成网站备案/视听许可、内容版权授权链与未成年人保护措施；这是避免整站被下线的前提，技术容灾只解决故障与劫持（见 `09`） |
| 支付合规 | 支付宝、微信支付需对应主体的商户资质并遵守渠道协议；加密货币支付在部分司法辖区（如中国大陆）被禁止，USDT 渠道按地区开关；应用商店包遵守商店内购规则（`05` C.9） |
| 多语言 | 用户端 9 种语言，阿拉伯语从右到左排版；界面文案可经 CDN 更新而不发版（`04` A.4、`05` A.6）；剧名、简介等内容的多语言不在当前范围 |

## 7. 非功能性要求

- **性能**：首帧 P50 ≤ 1.0s、P95 ≤ 2.5s；Web LCP ≤ 2.0s、INP ≤ 200ms；APP 冷启动 ≤ 1.5s、刷剧 60fps；API 读 P99 ≤ 150ms。完整预算见 `08`。
- **可用性**：核心读接口 SLA 99.95%；多 CDN、多域名、多线路，任一单点故障不影响播放；数据库 RPO ≤ 1 分钟、RTO ≤ 15 分钟。见 `09`。
- **SEO**：SSR + 分页面标题/描述模板 + 结构化数据 + sitemap + robots 开关；多入口 canonical 指向主入口。
- **可观测**：全链路 `x-request-id` + OpenTelemetry；播放 QoS 与域名切换埋点；运维侧另接 Umami 做 PV/UV。
- **安全**：全链路 TLS、用户端接口报文加密（HPKE）、视频 HLS 加密 + blob 播放、字段级加密、Argon2id、令牌轮换、请求签名、后台二次验证、审计哈希链、支付回调验签与对账、供应链冷却期。见 `10`。

| 频道 / channel | 某个维度取值的独立落地页 |
| 登录墙 / 试看 | 限制未登录用户观看的机制 |

| 天天奖券 | 每天领取抽奖号码，固定时间公开开奖，可自行校验 |
| 有效邀请 | 被邀请人绑定后 7 天内有效观看满 30 分钟且通过风控 |
| 回家的路 | 多域名回流页 |
| 看板定稿 | 每日凌晨汇总前一日数据并锁定 |
