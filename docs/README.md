# 短剧平台 · 功能与技术设计文档

本目录是「短剧内容平台」的设计文档集，覆盖**后端、前端（Web）、APP、运营后台**四端，细化到每个功能模块，并给出统一的性能、高可用与数据安全方案。

> 功能部分基于对参考站的页面结构、前端路由、接口与交互文案分析整理，并结合本仓库已有工程（`apps/` SvelteKit 前台、`admin/` React 后台骨架）给出落地方案。所有与具体内容相关的描述均做中性化处理。
> 技术版本基线核对于 **2026-10-21**。

## 系统四端一句话职责

- **后端 `service/`**：平台唯一数据与业务权威源。提供用户端、运营后台、开放平台三类 API，负责内容、播放鉴权与令牌、媒体转封装、统计埋点、任务调度与加密。
- **前端 `apps/`**：面向用户与搜索引擎的 Web 站，SvelteKit SSR + BFF，承担 SEO、首屏、沉浸式播放，不持有数据库与业务密钥。
- **共同约定**：用户端（Web、APP）9 种语言、接口报文加密、视频加密以 `blob:` 播放；运营后台只用中文、接口不加密。决策记录见 [`adr/`](./adr/)。
- **APP `mobile/`**：Flutter 原生客户端，强化竖屏沉浸式刷剧、本地续播、推送、多域名容灾与端侧安全加固。
- **运营后台 `admin/`**：内部内容生产与运营控制台，React SPA，独立私有域名 + 二次验证。

## 文档约定

- **[推断]**：参考站未明示、依据上下文推导的设计，落地时需产品确认。
- **状态/枚举**：以 `枚举值` 形式标注，字段名与接口对齐，可直接建表与定义 DTO。
- 用户端接口统一以 `/api/v1/` 开头，之后的部分沿用参考站已验证的命名（如 `/api/v1/me/state`、`/api/v1/episodes/:id/sources`）；后台接口统一以 `/api/admin/` 开头，与开放平台接口一样为建议命名（`07` 第 0.5 节）。
- 版本号为 2026-10 基线，实际以各端锁文件为准；升级流程见 `00` 第 6 节。
