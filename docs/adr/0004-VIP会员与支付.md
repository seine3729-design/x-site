# 0004 VIP 会员与支付渠道

状态：已采纳（设计），待实现；金币钱包部分由 `0005` 修订
日期：2026-10-21

## 背景

平台此前只有广告变现，分集 `access=vip` 是预留值。现在要启用 VIP：天卡、周卡、月卡、季卡、年卡，支持支付宝、微信支付、USDT。

## 决策

- 会员按订单购买，下单即支付。金币钱包见 `0005`：MVP 金币只能赚、不能买，充值金币有开关、默认关闭；订单接口为 `/api/pay/orders`，可购买的商品类型为会员套餐（启用后加金币套餐）。
- 五种套餐时长默认 1 / 7 / 30 / 90 / 365 天，价格分别按人民币（支付宝、微信）和 USDT 配置，USDT 不做实时汇率换算。
- 购买叠加顺延：新到期时间 = max(当前到期, 现在) + 套餐天数；每次变动写会员流水。MVP 不做自动续费。
- 只有注册用户能购买（游客身份绑定设备，丢失即失去会员）。
- 到账只认服务端结果：支付宝 / 微信异步通知验签 + 主动查单；USDT 由链上监听确认，默认 TRC-20，每单独立收款地址（服务端只有派生公钥，私钥离线）。
- 支付渠道可按客户端和地区（GeoIP 国家）开关。

## 备选方案与放弃原因

- 余额充值再消费：多一套账户与对账，当前没有其他消费场景。
- USDT 固定地址 + 唯一尾数：实现简单但用户易付错金额；保留为可切换模式。
- 自动续费（支付宝周期扣款、微信委托代扣）：需要额外签约资质，后续再评估。

## 影响

- 应用商店渠道（App Store、Google Play）销售数字内容须使用商店内购；商店包不能直接调起支付宝、微信或 USDT。商店包采用内购，或只登录查看已购会员、在网页购买（需按商店规则评估）；官网 APK 与 Web 使用三种渠道。
- 加密货币支付在部分司法辖区（如中国大陆）受禁止，渠道必须能按地区关闭。
- 忘记密码无法找回账号（`0001`），会员随账号丢失；提供凭支付凭证人工迁移剩余天数的客服流程，购买页需提示。
- 新增数据表、接口、后台页面与任务，详见 `01`–`11` 中的「会员与支付」。
