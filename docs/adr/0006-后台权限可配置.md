# 0006 后台权限可配置（管理员 → 角色 → 权限点 → 菜单）

状态：已采纳
日期：2026-10-22

## 背景

此前后台只有四种固定角色（超级管理员 / 运营 / 审核员 / 只读），权限矩阵写死在代码里（原 `03` 第 2.5 节），侧栏菜单也写死在前端。运营方要求在后台自行配置：新增角色、调整每个角色能看和能改的页面、管理管理员账号、调整侧栏菜单。

## 决策

- **权限点**：每个后台页面有「查看」`<页面>.view`，有写操作的页面另有「修改」`<页面>.edit`；少数需要单独授权的操作是独立权限点（`seo.analytics_code` 统计代码、`blocks.custom_html` / `ads.custom_html` 自定义 HTML）。权限点目录由代码与迁移定义（表 `admin_permission`），后台只能授予，不能新建——没有后端校验的权限点没有意义。每个后端路由用 `RequirePage` / `RequirePermission` 声明所需权限点，启动时校验它们都在目录中。
- **角色**：可在后台新建、改名、停用、删除（`admin_role`）。只内置超级管理员：唯一的超级角色，拥有全部权限点（含以后新增的），不能改权限、停用或删除。运营、审核员等角色由超级管理员按团队分工新建，新角色没有任何权限。每个管理员属于一个角色。
- **角色权限**：先选角色，再在权限树中勾选。权限树按菜单结构排列：一级页面直接带权限点；目录展开后是二级页面，每个页面的权限点列在同一行。目录和页面的勾选框有三态（全部 / 部分 / 没有），勾选目录即授予其下全部权限点。授予某页面的任一权限点自动带上该页面的「查看」。
- **防越权**：非超级管理员不能修改自己的账号、自己所属角色的权限，只能授予或收回自己拥有的权限点；只有超级管理员能授予超级管理员角色、操作超级管理员账号；至少保留一个可用的超级管理员（事务内加锁检查）。
- **即时生效**：每个后台请求读一次账号、角色与权限点，改角色、改权限、停用账号或角色立即生效；重置密码与强制下线让账号的会话版本加一，旧会话全部作废。
- **菜单**：后台菜单存表（`admin_menu`），最多两级：一级菜单是目录、页面或外链，二级菜单是目录下的页面或外链，目录只能是一级。默认一级菜单为「运营数据看板」「剧集分析」两个页面和七个目录。页面由代码提供（路径即前端路由），只能改名称、图标、上级目录、排序与显示；目录与外部链接可增删。侧栏按「可见 + 有查看权限」过滤后由接口下发。后台菜单页是可展开的两级列表。隐藏菜单不等于收回权限。
- 超管操作的二次验证仍在 S2-6；标为「高敏」的权限点届时操作需重新验证。

## 备选方案与放弃原因

- 继续用固定矩阵：不满足在后台配置的要求。
- 保留运营 / 审核员 / 只读三个内置角色：各团队分工不同，预置的授权多半要改，内置角色还不能删除；只保留超级管理员，其余由管理员按需新建更清楚。
- 角色 × 权限点的矩阵界面：83 个权限点乘以多个角色，表格又宽又长，看不出菜单层级；改为一次编辑一个角色的权限树。
- 可在后台新建任意权限点（如部分开源后台）：权限点必须对应后端的校验代码，界面上新建的权限点不会被任何接口检查，徒增误导。
- 菜单不限层级：后台页面不到 50 个，两级足够；更深的层级让侧栏和权限树都更难扫读。
- 一个管理员多个角色：权限取并集更难判断「为什么能改」；需要组合时新建一个角色即可。
- 前端按菜单路由自动推导权限：前后端各自判定容易不一致，权限必须在后端判定。
- 权限表进程内缓存 + Pub/Sub 失效：后台请求量很小，每次读库更简单且没有失效窗口；量大后再加缓存。

## 影响

- 新表 `admin_menu`、`admin_permission`、`admin_role`、`admin_role_permission`；`admin_user.role` 改为 `role_id`，新增 `session_version`（迁移 00003）。迁移 00005 把菜单改为一级 / 二级（数据看板、剧集分析提为一级页面，删除「概览」目录，目录补默认图标），删除没有成员的三个预置角色（有成员的转为自定义角色）；两者都可回滚。
- `/admin-api/me` 返回角色名称、`is_super` 与已授予的权限点编码；`/admin-api/me/menus` 返回两级侧栏，`/admin-api/permissions` 返回权限树；另有管理员、角色、后台菜单接口（`07` 第 2 节，契约 0.5.0）。
- 新增后台页面需要：在迁移中登记菜单与权限点、在前端 `config/navigation.ts` 登记路由、后端路由声明权限点。
- 后台「权限」目录：管理员、角色、角色权限、后台菜单。
