# 任务规格

复杂任务在进入“进行中”前，从 [`TEMPLATE.md`](./TEMPLATE.md) 创建 `specs/<任务编号>.md`。

适用条件：

- 任务规模为 `L`；
- 涉及两个及以上应用/模块；
- 新增或修改 API、数据状态机、鉴权、附件、迁移；
- 验收无法在任务表一行中明确；
- 风险较高或需要分切片交付。

规格是任务的实施合同，不替代主设计文档：

- 产品规则回写 `01`；
- 数据语义回写 `03`；
- 接口机器契约写入 `api/openapi.yaml`，`08` 只做索引；
- 跨模块决策进入 `adr/`；
- 规格记录该任务如何落地、验证和回滚。

状态使用：`草案 / 待评审 / 已批准 / 进行中 / 已完成 / 已取消`。完成后补实际证据，不删除原验收标准。
