# 架构决策记录（ADR）

## 规则

1. 从 [`TEMPLATE.md`](./TEMPLATE.md) 复制并使用四位递增编号；
2. 提议先评审，只有用户/决策人明确同意后改为“已采纳”；
3. 已采纳 ADR 不静默重写结论；新决策创建新 ADR，并在旧 ADR 标记“已取代”；
4. 每份 ADR 写备选方案、负面后果、迁移、回滚和复审触发器；
5. 敏感信息、账号、真实域名凭据和内部访问细节不得写入 ADR。
