# Runbooks 运维手册

Runbook 用于可预见的生产故障和高风险操作。技术栈与生产环境确定后，从 [`TEMPLATE.md`](./TEMPLATE.md) 创建具体文档。

上线前至少覆盖：

- API 错误率/延迟升高；
- 数据库不可写或连接池耗尽；
- Outbox/Worker/通知积压；
- 附件扫描失败或恶意文件事件；
- 私密内容缓存/权限泄露；
- 会话、邀请或密钥疑似泄露；
- 对象存储不可用；
- 数据库迁移失败与应用回滚；
- 备份恢复；
- 紧急只读/冻结写。

规则：

- 步骤必须可执行，不写“联系相关人员”而不说明角色与升级条件；
- 命令使用安全占位符，不记录真实密钥、账号或内部敏感地址；
- 先说明影响和风险，再执行高风险动作；
- 每次演练/事件后更新“最后验证日期”和证据；
- 不使用未经确认的破坏性命令；数据修复优先隔离恢复和前滚。
