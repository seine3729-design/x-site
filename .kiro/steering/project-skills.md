# 先读技能，再写代码

本仓库的开发规范与设计规范以技能形式放在 `.claude/skills/`。

在编写或修改任何代码、文档之前：

1. 读取 `.claude/skills/project-skills-index/SKILL.md`。
2. 按其中的「技能路由」读取本次任务适用的全部 `.claude/skills/<技能名>/SKILL.md`（界面相关同时读 `ui-ux-pro-max`、`ui-styling`）。
3. 读取路由中指向的 `docs/` 章节。
4. 回复开头写明「参考技能：…」。

完成标准见 `.claude/skills/project-skills-index/references/definition-of-done.md`。仓库总体约定见根目录 `AGENTS.md`。
